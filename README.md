# Add Bedrock

Ferramenta para gerar links compartilháveis de servidores Minecraft Bedrock.

## Demonstração

https://wjldo.github.io/Add-Bedrock-Server/

## Recursos

* Geração de links Bedrock
* Copiar link com um clique
* Abrir link diretamente
* Compatível com dispositivos móveis
* Interface moderna

## Como usar

1. Informe o nome do servidor
2. Informe o IP ou domínio
3. Informe a porta
4. Clique em **Gerar Link**
5. Compartilhe o link gerado
